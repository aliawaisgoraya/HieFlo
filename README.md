# HieFlo

Source and backups for HieFlo, an AI automation business for small businesses.

## Structure

- `n8n-workflows/` — nightly backups of n8n workflows (JSON exports)
- `lovable-apps/` — notes and links for client dashboards built in Lovable
- `docs/` — SOPs and workflow documentation

## Notes

- Never commit API keys, passwords or client data. n8n credentials are not included in workflow exports.
